# 🤪 搞怪脸工坊

上传人物照片，AI 自动识别五官，一键恶搞：大眼萌、香肠嘴、大头娃娃、外星人、小猪、小丑……还能加贴纸、表情包文字和滤镜。

**所有处理都在浏览器本地完成，照片不会上传到任何服务器。**

## 功能

| 模块 | 内容 |
|---|---|
| 🤖 AI一键 | 自动识别人脸 68 个五官点（支持多张脸）；五官改造 12 种、整套变身 6 种、自动贴到脸上 10 种 |
| 变形刷 | 放大 / 缩小 / 推移 / 旋转扭曲 / 局部还原，按住持续生效 |
| 整图搞笑 | 中心放大、鱼眼、哈哈镜、拉长、波浪、左右脸对称、漩涡 |
| 贴纸 | 画的贴纸（八字胡、小丑鼻、腮红、一字眉、圆眼镜）＋ 40 多个表情，可拖动、缩放、旋转、翻转 |
| 文字 | 表情包上下字幕 |
| 滤镜 | 黑白、老照片、反色、马赛克、波普、卡通色块、绿巨人、晒伤红 |
| 🔄 旋转翻转 | 任意角度实时旋转（可自动裁掉空白角）、±1° 微调、左右转 90°、左右翻转、上下翻转；贴纸和五官点跟着一起转 |
| 🧩 版面拼图 | 大头贴机玩法：单图／上下／左右／三竖／三横／田字 6 种版面，每格独立上传、独立恶搞、独立撤销；可设整体比例、填满或完整显示、边框粗细和颜色、圆角、底部签名文字，导出成一张拼图 |

另外支持：撤销（Ctrl+Z）、还原原图、一次选多张自动填进空格子、拖放 / 粘贴上传、图片缩放和拖动查看、导出 JPG。

## 目录

```
index.html      页面
style.css       样式
app.js          全部逻辑
lib/face-api.js 人脸识别库（@vladmandic/face-api 1.7.15，内含 TensorFlow.js，MIT 协议）
models/         识别模型（SSD MobileNet 人脸检测 + 68 点五官），约 6 MB
_headers        Cloudflare Pages 缓存设置
```

纯静态网站，没有构建步骤，也不依赖任何外部 CDN（国内访问也稳定）。

## 部署到 Cloudflare Pages

1. 把整个文件夹推送到一个 GitHub 仓库。
2. Cloudflare 控制台 → Workers & Pages → 创建 → Pages → 连接 Git → 选这个仓库。
3. 构建设置：**框架预设选“无”，构建命令留空，输出目录填 `/`**（或留空）。
4. 部署完成后，打开 `xxx.pages.dev` 即可使用。

## 本地预览

不能直接双击 `index.html` 打开（浏览器会拦截模型文件加载），需要起一个本地服务器：

```bash
python -m http.server 8000
# 然后浏览器打开 http://localhost:8000
```

## 说明

- 识别对正脸、清晰的照片效果最好；侧脸、太小或卡通图可能识别不到，这时可以用“变形刷”手动改。
- 图片最长边会缩放到 1200 像素，以保证手机上也流畅。
